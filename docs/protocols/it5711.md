# Gigabyte IT5711 RGB controller (USB HID)

Notes for the B860M GAMING X WIFI6E controller, written for this project. Byte offsets are zero-based. Multi-byte integers are little-endian.

## Device

- USB `VID 048D`, `PID 5711`, interface `MI_01`, collection `Col02`. Firmware seen: 0.0.28.3.
- All traffic is HID **feature reports**, 64 bytes, first byte = report id `0xCC`.
- Reads: send a request feature report, then get feature report `0xCC` (64 bytes back).

## Simple command

`[0]=0xCC [1]=cmd [2]=a [3]=b`, rest zero.

| cmd | a | b | Meaning |
|---|---|---|---|
| `0x60` | 0 | 0 | request device info (then get feature report) |
| `0x61` | 0 | 0 | request extra calibration (then get feature report) |
| `0x48` | 0/1 | 0 | lamp array off/on. Send 0 at init when info `support_cmd_flag >= 2` |
| `0x31` | 0/1 | 0 | audio "beat" mode off/on. Send 0 at init |
| `0x32` | mask | 0 | built-in effect **disable** mask for ARGB headers: D_LED1 `0x01`, D_LED2 `0x02`, D_LED3 `0x08`, D_LED4 `0x10`. Bit set = direct per-LED mode. Wait 50 ms after |
| `0x34` | `(d2<<4)\|d1` | `(d4<<4)\|d3` | ARGB LED count class per header: 0 = up to 32, 1 = 64, 2 = 256, 3 = 512, 4 = 1024 |
| `0x28` | `0xFF` | `0x07` | apply all effect slots at once (fast apply) |
| `0x20`..`0x27`, `0x90`..`0x92` | 0 | 0 | clear effect slot (reset) |
| `0x47`, `0x5E` | | | save to flash. **Never send.** |

## Device info reply (after `0x60`)

| Offset | Size | Field |
|---|---|---|
| 0 | 1 | report id |
| 1 | 1 | product |
| 2 | 1 | device number |
| 3 | 1 | strip detect |
| 4 | 4 | firmware version, bytes b0.b1.b2.b3 |
| 8 | 1 | current LED count classes, high: D_LED3 low nibble, D_LED4 high nibble |
| 9 | 1 | current LED count classes, low: D_LED1 low nibble, D_LED2 high nibble |
| 10 | 1 | strip control length |
| 11 | 1 | support_cmd_flag |
| 12 | 28 | product string, NUL padded |
| 40 | 4 | calibration spare0 |
| 44 | 4 | calibration D_LED1 |
| 48 | 4 | calibration D_LED2 |
| 52 | 4 | calibration mainboard |
| 56 | 4 | chip id |
| 60 | 4 | calibration spare1 |

Extra calibration reply (after `0x61`): offset 4 = D_LED3, 8 = D_LED4, 12 = spare2, 16 = spare3 (4 bytes each).

### Byte-order calibration value

32-bit value. Byte 0 = position of **blue** inside an LED triple, byte 1 = position of **green**, byte 2 = position of **red** (each 0..2, all distinct). Value 0 = header off / not calibrated. Example: a GRB strip has G at 0, R at 1, B at 2, so byte 0 = 2, byte 1 = 0, byte 2 = 1, value `0x00010002`.
If the reply value is 0 or invalid, use the configured fallback order (this PC: D_LED1..3 = `GRB`).

## Per-LED color packet (ARGB headers in direct mode)

| Offset | Size | Field |
|---|---|---|
| 0 | 1 | `0xCC` |
| 1 | 1 | header: D_LED1 `0x58`, D_LED2 `0x59`, D_LED3 `0x62`, D_LED4 `0x63` |
| 2 | 2 | byte offset of first LED in this packet = first LED index * 3 |
| 4 | 1 | byte count in this packet = LEDs in packet * 3 |
| 5 | 57 | up to 19 LED triples; inside triple i at `5 + i*3`, put R at `+posR`, G at `+posG`, B at `+posB` |

A strip of N LEDs takes ceil(N/19) packets. 24 LEDs = 19 + 5.

## Effect packet (single-color zones: 12V strip, motherboard LEDs)

| Offset | Size | Field |
|---|---|---|
| 0 | 1 | `0xCC` |
| 1 | 1 | slot header: `0x20 + led` for led 0..7, `0x90 + (led - 8)` for led 8..10 |
| 2 | 4 | zone mask = `1 << led` |
| 6 | 4 | zone mask high = 0 |
| 10 | 1 | reserved 0 |
| 11 | 1 | effect type: 1 = static (only one used here) |
| 12 | 1 | max brightness: 255 |
| 13 | 1 | min brightness: 0 |
| 14 | 4 | color0 = `(R<<16) \| (G<<8) \| B` |
| 18 | 4 | color1 = 0 |
| 22 | 8 | periods, 0 for static |
| 30 | 4 | effect params, 0 |
| 34 | 30 | zero |

Apply after effect packets: `[0]=0xCC [1]=0x28 [2..5]=OR of the zone masks just written [6..9]=0`.

## Init sequence

1. `0x60`, get info. Fail init if the reply is shorter than 64 bytes.
2. `0x61`, get extra calibration.
3. If `support_cmd_flag >= 2`: `0x48 0`.
4. Clear slots `0x20`..`0x27`, `0x90`..`0x92`, then fast apply `0x28 0xFF 0x07`.
5. `0x31 0`.
6. `0x34` with LED count classes from config.
7. `0x32` with the mask of every ARGB header used in direct mode, wait 50 ms.
8. Write all zones once.
